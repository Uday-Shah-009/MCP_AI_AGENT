# MCP_AI_AGENT 🚀

An AI agent built using the **Model Context Protocol (MCP)** to automate posting on X.com (formerly Twitter).

## 🌟 Project Overview

**MCP_AI_AGENT** is a JavaScript-based application that leverages the MCP standard—developed by Anthropic and adopted by OpenAI, Google, and others—to interact with X.com and autonomously schedule, compose, and post content.

---

## Features

- ✅ Uses MCP clients and tool servers to integrate seamlessly with X.com  
- ✍️ Automatically composes and posts updates on user-defined schedules  
- 🔄 Modular MCP server architecture: separates client logic from posting workflows  
- 🔐 Designed for extensibility and secure tool-based automation

---
